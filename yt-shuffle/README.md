# YT Shuffle – 登録チャンネル再発見（Chrome / Brave 拡張機能）

YouTube をいつも同じような動画ばかり見て飽きてきた人向けに、**自分の登録チャンネルや好みに近いチャンネルの中から、まだ見ていない人気動画をランダムに提案する**拡張機能です。

| 登録チャンネル・シャッフル | 近いチャンネル発見 |
| --- | --- |
| 登録しているのに**あまり見ていないチャンネル**を重み付きでランダムに選び、そのチャンネルの**人気順（再生回数が多い順）の動画のうち未視聴のもの**を出します。 | **よく見る登録チャンネル**の動画の関連動画をたどり、**まだ登録していない近いチャンネル**を探して、その人気の未視聴動画を出します。 |

- **投稿日で絞り込み**: パネルの「投稿日」で期間を選べます。
  - 選択肢: 24時間以内 / 3日以内 / 1週間以内 / 1か月以内 / 3か月以内 / 半年以内 / 1年以内 / 3年以内
  - 「期間を指定…」を選ぶと、「12時間以内」「10日以内」「2年以内」のように数字と単位（時間・日・週間・か月・年）を自由に指定できます。
  - 期間を変えると自動でシャッフルし直します。
- **パネルの幅**: 初期幅は 720px です。広げ方は次の2通りです。広いときはサムネイルが大きいグリッド表示になります。
  - ヘッダーの ↔ ボタンで 480 → 720 → 960 → 1280px と切り替え
  - パネル左端のドラッグで自由に変更（幅は保存されます）
- **おまかせ1本**: 候補の中からスコアの高いものを 1 本選んで、すぐ再生します。
- **スキップ**: 各動画の下の「スキップ」を押すと、その動画をしばらく出さなくなります（初期値 30 日、設定で変更できます）。空いたところには次の候補が自動で補充されます。
- **再生中のスキップ**: おすすめから開いた動画では、画面右下に「スキップして次のおすすめへ」ボタンが出ます。押すか <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> で、今の動画をスキップして次のおすすめを再生します。
- **興味なし / チャンネル除外**: その動画、またはそのチャンネルを今後ずっと出しません（設定画面から戻せます）。
- **視聴済みの判定**: YouTube の視聴履歴、一覧に出る赤い再生済みバー、拡張機能が記録した視聴を合わせて使います。
- **興味との近さ**: 視聴履歴のタイトルからよく見るキーワードを集め、近い動画を少し優先します。
- API キーや Google Cloud の設定は不要です。**YouTube にログインしていれば、そのまま使えます。**

## インストール（Chrome / Brave 共通）

1. このリポジトリをダウンロードして展開します。GitHub の「Code → Download ZIP」を使うか、`git clone` してください。
2. アドレスバーに次を入力して、拡張機能の管理画面を開きます。
   - Chrome: `chrome://extensions`
   - Brave: `brave://extensions`
3. 右上の **「デベロッパー モード」** をオンにします。
4. **「パッケージ化されていない拡張機能を読み込む」** を押し、`yt-shuffle/extension` フォルダを選びます。
5. ツールバーのパズルアイコンから **YT Shuffle** をピン留めしておくと便利です。

> Chrome ウェブストアには公開していないので、デベロッパーモードでの読み込みになります。ブラウザの起動時に「デベロッパーモードの拡張機能」についての警告が出ることがありますが、そのまま使えます。

## 使い方

1. YouTube に**ログインした状態で** https://www.youtube.com を開きます。
2. パネルを開くには、次のどれかを使います。初回は、登録チャンネルと視聴履歴（直近 10 ページ分）を自動で読み込みます。
   - 画面右下の **サイコロボタン**
   - ツールバーの拡張機能アイコン
   - <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>Y</kbd>（ショートカットは `chrome://extensions/shortcuts` で変更できます）
3. 上のタブで **「登録チャンネル」** か **「近いチャンネル」** を選び、**シャッフル** を押します。
4. 気になる動画をクリックして再生します。**おまかせ1本** を押すと、1 本を自動で選んですぐ再生します。

設定画面（パネルの歯車ボタン）では、次のことができます。

- 人気・興味・ランダム度の重み付け
- ショート動画の除外
- 動画の長さの下限・上限
- 1 回に調べるチャンネル数
- Google Takeout からの取り込み

### 何年も前の履歴まで反映したいとき（任意）

自動で読み込む視聴履歴は直近の分だけです。昔の履歴も使いたいときは、[Google Takeout](https://takeout.google.com/) で「YouTube と YouTube Music」をエクスポートし、設定画面から次のファイルを取り込んでください。

- `subscriptions.csv`
- `watch-history.json`（`.html` でも可）

## しくみ

すべての処理はブラウザの中だけで行います。通信先は、ログイン中のセッションで開く `www.youtube.com` だけです。データは `chrome.storage.local` に保存し、外部には送信しません。

| 使うデータ | 取得元 |
| --- | --- |
| 登録チャンネル | `youtube.com/feed/channels`（チャンネル管理ページ） |
| 視聴履歴 | `youtube.com/feed/history` ＋ 拡張機能が記録した視聴（30 秒以上、短い動画は半分以上再生で記録） |
| チャンネルの人気動画 | 各チャンネルが自動で持つ「人気の動画」再生リスト（`UULP…`）。取れないときは RSS → 「動画」タブ → 最新動画 RSS の順に切り替えます |
| 近いチャンネル | よく見る登録チャンネルの動画ページにある関連動画 |
| 期間指定時の新しい動画 | 各チャンネルの「動画」タブ（最新約 30 件）と、1 か月以内の期間なら登録チャンネルの新着フィード（`/feed/subscriptions`）も使います |

おすすめの順位は、次の点を重み付けして合計したスコアで決めます。

- **人気度**: 再生回数の多さと、そのチャンネルの中での人気順
- **興味**: 視聴履歴のタイトルとの近さ
- **ランダム**
- **近さ**: 近いチャンネル発見のときだけ。いくつの登録チャンネルから辿れたか

投稿日は「3 年前」「2 日前」のような表示から逆算するので、目安の精度です。例えば「1 年前」は 1 年ちょうどとして扱います。期間を指定したときは、投稿日がわからない動画は出しません。

結果は、同じチャンネルが並ばないように 1 チャンネル 2 本までにしています。直近で出したチャンネルは、しばらく出にくくなります。

## うまく動かないとき

- パネル下部の **「動作診断」** を押すと、次の項目がそれぞれ取得できているかを確認できます。
  - 登録チャンネル
  - 視聴履歴
  - 人気動画
  - 関連動画

  表示された内容をコピーして共有してもらえれば、原因を調べやすくなります。
- この拡張機能は YouTube の公式 API ではなく、**YouTube の Web ページに埋め込まれているデータ**を読み取っています。YouTube の画面が変わると、一部が取れなくなることがあります。その場合でも、取れない部分は別の取得方法に切り替えて動くようにしています。
- 登録チャンネルが読み込めないときは、Takeout の `subscriptions.csv` を取り込むと、それを使って動きます。

## 開発

```bash
cd yt-shuffle
npm test               # 単体テスト（Node 20 以上）
npm i -D playwright    # E2E テストを動かす場合のみ
npm run e2e            # Chromium に拡張機能を読み込み、ダミーの YouTube で一連の操作を確認
```

```
extension/
  manifest.json          Manifest V3
  background.js          ツールバーアイコン・ショートカット・視聴記録の書き込み
  lib/extract.js         YouTube ページの解析（旧形式 videoRenderer / 新形式 lockupViewModel の両対応）
  lib/recommend.js       チャンネルの抽選・スコアリング・多様化
  lib/store.js           保存（視聴済みは動画 ID の先頭文字で 64 分割）
  lib/rss.js, takeout.js RSS / Google Takeout の読み込み
  content/yt-api.js      youtube.com からの取得
  content/engine.js      同期・シャッフル・近いチャンネル発見・診断
  content/panel.js       画面右側のパネル UI（Shadow DOM）
  content/tracker.js     視聴の自動記録（page-hook.js がプレイヤーからチャンネル ID を渡す）
  options/               設定画面
test/                    単体テスト・E2E テスト・YouTube ページのフィクスチャ
```
