YT Shuffle

登録チャンネルの「まだ見ていない人気動画」と、好みに近いチャンネルを発見する拡張機能

使い方

  1. YouTube にログインした状態で youtube.com を開きます。
  2. 画面右下の サイコロボタン、ツールバーの拡張機能アイコン、または Alt+Shift+Y でパネルを開きます。初回は登録チャンネルと視聴履歴を自動で読み込みます。
  3. 「登録チャンネル」タブ: 登録しているのに見ていないチャンネルから、人気の未視聴動画を選びます。
    「近いチャンネル」タブ: よく見るチャンネルに近い、まだ登録していないチャンネルの人気動画を選びます。
  4. シャッフルで候補を一覧表示、おまかせ1本ですぐ再生。気分じゃない動画はスキップ（しばらく出さない・代わりを補充）、興味がない動画は興味なしで今後出なくなります。
  5. おすすめから開いた動画では、右下の「スキップして次のおすすめへ」ボタン、または Alt+Shift+N で次の動画へ進めます。

データの状態

データはすべてこのブラウザの中（chrome.storage）に保存され、外部には送信されません。

Google Takeout から取り込み（任意）

通常は YouTube から自動で読み込むので不要です。何年も前の視聴履歴まで反映したいときや、自動読み込みがうまくいかないときに使ってください。

  1. Google Takeout で「すべて選択解除」→「YouTube と YouTube Music」だけを選択。
  2. 「複数の形式」で 履歴 を JSON に変更（HTML のままでも取り込めます）。
  3. ダウンロードした zip を展開し、下から subscriptions.csv と watch-history.json を選択。
